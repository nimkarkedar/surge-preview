The problem

Surge for Agents lets teams building AI agents give them a Bitcoin-backed credit line to manage for its owner through the Surge API, while the owner's Bitcoin sits in a vault whose rules no agent can bend.

  • An agent can't open a bank account or pass a credit check: credit is built around underwriting a person or a company.

  • An agent that needs dollars can only sell its owner's Bitcoin.

  • Handing an agent the keys to a Bitcoin wallet means trusting it with everything.

A valet key for your Bitcoin

A valet key starts the car but won’t open the trunk. Surge gives an agent the same kind of access: enough to run the credit line, never enough to take the Bitcoin.

What an agent can do

Open a credit line for its owner, draw USDC, repay, add Bitcoin and supply USDC to earn yield, through the Surge API, under published terms: up to 50% of the Bitcoin’s value, at a rate shown live.

What an agent can never do

  • Send the Bitcoin anywhere but back to its owner
  • Move it out of the vault alone
  • Change the vault's rules

The collateral can only be repaid out, liquidated or recovered by its owner.

How it works

  • Get API keys and let your agent open a test credit line in the sandbox, with test Bitcoin and USDC.

  • The owner pledges BTC. It moves into its own vault on the Bitcoin network.

  • The agent draws and repays. USDC settles in about 30 minutes, when liquidity is available, and the agent can read the line's position live, at any time.

  • On repayment, the same Bitcoin returns to its owner.

Questions

How does an agent stay in control?

Every credit line's loan-to-value can be read live, at any time. An agent can check as often as it likes, and repay or add Bitcoin well before a line gets close to liquidation.

Can AI coding tools read the docs?

Yes. Surge Docs are agent-ready, and they publish llms.txt so AI tools can read them directly.

Do we need a lending license?

Surge is software and isn't the lender: the USDC comes from independent lenders. Whether you need a license depends on your markets and how you offer credit, so we walk your counsel through the structure before you launch.
